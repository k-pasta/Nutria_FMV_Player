# Nutria FMV Player

**Nutria FMV Player** plays interactive movies (`.fmv`) made with [Nutria FMV Maker](https://github.com/k-pasta/Nutria_FMV_Maker): the story's own main menu, its videos with the answers over them, its logic, music, subtitles (in the viewer's language), and a pause menu with saving and loading. Published under the **GPLv3 license**.

Keys: Escape or Space for the pause menu, 1–9 to pick an answer, Enter to go on, F or F11 for full screen, Up and Down for the volume.

For more information, please visit the project's documentation page: [Nutria FMV Documentation](https://rigascg.com/nutriafmvdocs/)
